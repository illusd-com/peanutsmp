遊玩說明

歡迎來到 PeanutSMP！純原版、雙端互通生存伺服器的完整說明。

關於伺服器

PeanutSMP 是一個完全原版的 Minecraft 生存伺服器，支援 Java 版與基岩版互通。 沒有外掛、沒有領地系統、沒有自訂經濟，只有官方原版指令與機制。

伺服器資訊

位址：play.peanutsmp.de5.net
Java Port：25565（預設）
基岩版 Port：19132（預設）
互通：是 · Java + 基岩版
類型：純原版 · 無外掛

如何加入

Java 版

  1. 開啟 Minecraft Java 版，進入「多人遊戲」。
  2. 點選「新增伺服器」。
  3. 伺服器位址填入 play.peanutsmp.de5.net（Port 預設 25565，可省略）。
  4. 完成後連線即可進入。

基岩版

  1. 開啟 Minecraft 基岩版（手機、平板或 Windows）。
  2. 進入「伺服器」分頁，點選「新增伺服器」。
  3. 位址填入 play.peanutsmp.de5.net，連接埠 19132（預設）。
  4. 儲存後點選伺服器連線。

原版指令

伺服器只開放原版指令，沒有額外外掛指令。依權限等級可使用例如：

  • /tp — 傳送至指定座標
  • /gamemode — 切換遊戲模式（需權限）
  • /time set — 設定時間（需權限）
  • /weather — 設定天氣（需權限）
  • /give — 給予物品（需權限）
  • 其他原版指令依伺服器權限設定開放

一般玩家預設以生存模式遊玩，特殊指令請詢問管理員或於 Discord 確認。

直接在遊戲中輸入上方指令即可傳送到末地傳送門附近。
